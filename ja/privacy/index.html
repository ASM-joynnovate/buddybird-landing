プライバシーポリシー

公告日 2026年10月20日 · 施行日 2026年10月20日

BuddyBird（以下「本サービス」といいます。）は、joynnovate（以下「運営者」といいます。）が運営するサービスであり、利用者の個人情報を重要なものと考え、個人情報保護法（韓国「개인정보 보호법」）その他の関係法令を遵守します。

本サービスは、会員登録・ログインを行わずにご利用いただけるものであり、利用者ご本人の氏名・メールアドレス・電話番号等の直接的な識別情報は収集しません。ただし、アプリの機能提供および品質・エラー分析のため、分析ツールを通じて以下の情報を収集・処理しており、その内容を次のとおり公開します。

第1条（個人情報の処理目的）

本サービスは、会員登録、ログイン、決済、相談、広告・マーケティングの機能を提供していません。ただし、次の目的のために個人情報を収集・利用します。

  • アプリの利用統計および使いやすさの分析
  • 異常終了（クラッシュ）およびエラーの診断・修正
  • プッシュ通知等のアプリ機能の提供
  • アプリの互換性および性能の改善

第2条（処理する個人情報の項目）

1. 分析ツールを通じて自動的に収集される項目

  • 端末および識別子：Android広告ID（AAID）、アプリインスタンスID、匿名インストールID（UUID）、プッシュ通知トークン（FCM）、クラッシュ分析用インストール識別子（iOSでは、トラッキングに同意した場合は広告識別子（IDFA）を含みます。）
  • おおよその位置：IPアドレスから推定される市区町村・地域レベルの位置（精密な位置情報ではありません。）
  • アプリの利用記録：画面遷移、学習セッション、単語の録音・再生等のアプリ内イベント、セッションリプレイ（タップ・スワイプ等の画面操作の動線）
  • 端末・環境情報：アプリのバージョン、OSのバージョン、端末のモデル、言語設定
  • 異常終了（クラッシュ）および診断情報：スタックトレース、クラッシュ発生時の端末の状態等

2. 利用者が直接入力する項目

  • インコ・オウム（ペット）の名前、種類（species）、年齢、学習目標
  • 利用者が登録・修正した学習単語の名称

3. 利用者が同意した場合に限り収集する項目

  • 学習中に録音された音声および利用者が録音した単語の音声ファイル、録音日時・長さ等の録音情報、匿名識別子（Firebase匿名uid）、アプリのバージョン・端末情報

上記の項目は、インコ・オウムの発音学習機能の開発および改善のため、アプリ内の音声収集に関する同意画面で同意した場合に限り、サーバーへ送信されます。同意しない場合、録音ファイルは端末内にのみ保存され、同意を拒否した場合でも本サービスのご利用に違いはありません。

上記の入力項目のうち、インコ・オウムの名前・学習単語の名称等の一部のテキストは、使いやすさの分析のため、分析ツール（Google Firebase、Microsoft Clarity）へ送信されます。これは飼い主ご本人の情報ではなく、ペットおよび学習コンテンツに関する情報です。

4. 収集しない項目

  • 利用者ご本人の氏名、メールアドレス、電話番号等の直接的な識別情報
  • 正確な（GPS）位置情報
  • 写真・動画（プロフィールのアバター写真は端末内でのみ使用され、外部へ送信されません。）

第3条（個人情報の収集方法）

本サービスは、次の方法により個人情報を収集します。

  • アプリの利用過程における分析ツール（Google Firebase Analytics・Crashlytics・Cloud Messaging、Microsoft Clarity）を通じた自動収集
  • 利用者がアプリ内で直接入力する情報
  • 音声収集に同意した利用者の録音ファイルの運営者サーバーへの送信

収集されるすべての情報は、情報通信網を通じて暗号化（HTTPS/TLS）されたうえで送信されます。

第4条（個人情報の処理および保有期間）

自動的に収集される分析・診断情報は、各分析サービス提供者のデータ保管ポリシーに従って保管されます（例：Firebase Analyticsは標準で最大14か月、Firebase Crashlyticsは約90日）。

利用者が入力した情報（インコ・オウムの情報、学習単語等）は原則として端末内に保存され、アプリを削除すると、端末に保存された情報および匿名識別子もあわせて削除されます。

音声収集に同意したことによりサーバーへ送信された録音ファイルおよび録音情報は、収集日から180日経過後に自動的に削除されます。

第5条（個人情報の第三者提供）

本サービスは、利用者の個人情報を外部に販売せず、法令に特別の定めがある場合を除き、第三者に提供しません。

ただし、本サービスの運営に必要な分析・エラー診断業務を、下記第6条のとおり外部の専門サービスに委託しています。

第6条（個人情報の処理の委託および国外移転）

本サービスは、アプリの品質向上ならびに利用統計およびエラーの分析のため、以下のとおり個人情報の処理業務を国外のサービスに委託しています。また、本サービスのサーバー運営のため、韓国国内リージョンのクラウドサービスを利用しています。

1. Google LLC（Firebase）

  • 提供を受ける者：Google LLC
  • 移転先の国／保管場所：米国
  • 移転する項目：端末・広告識別子、おおよその位置、アプリの利用記録、クラッシュ・診断情報等
  • 委託業務：利用統計の分析（Analytics）、異常終了の診断（Crashlytics）、プッシュ通知（Cloud Messaging）
  • 移転の時期および方法：アプリ利用時に、情報通信網を通じて暗号化（HTTPS/TLS）されたうえで送信

2. Microsoft Corporation（Clarity）

  • 提供を受ける者：Microsoft Corporation
  • 移転先の国／保管場所：米国
  • 移転する項目：アプリの利用記録、セッションリプレイ、端末情報、利用者の行動データ等
  • 委託業務：使いやすさの改善およびユーザー体験の分析
  • 移転の時期および方法：アプリ利用時に、情報通信網を通じて暗号化（HTTPS/TLS）されたうえで送信

3. Amazon Web Services, Inc.（AWS）

  • 受託者：Amazon Web Services, Inc.
  • 保管場所：大韓民国（ソウルリージョン）
  • 処理する項目：音声収集に同意した利用者の録音ファイル、録音情報、匿名識別子、アプリのバージョン・端末情報
  • 委託業務：サーバーの運営および録音ファイルの保管
  • 保有期間：収集日から180日経過後に自動削除

第7条（個人情報の収集・利用に関する同意および拒否の方法）

利用者は、分析・トラッキングを目的とする個人情報の収集について、次のとおり選択することができます。

  • iOS：アプリの初回起動時に、トラッキングへの同意（App Tracking Transparency）を確認します。拒否された場合、広告識別子（IDFA）を含む分析・トラッキングデータの収集は無効になります（クラッシュ診断を除きます。）。［設定］→［プライバシーとセキュリティ］→［トラッキング］から変更することができます。
  • Android：分析・診断情報はアプリの機能提供のために自動的に収集され、アプリ内で個別にオフにすることはできません。収集の停止をご希望の場合は、アプリを削除してください。

同意を拒否された場合でも、アプリの主要な学習機能は通常どおりご利用いただけます。

第8条（14歳未満の児童の個人情報の処理）

本サービスは、特定の年齢層を対象としない全年齢向け（アプリストアの年齢レーティング：満3歳以上）のアプリケーションであり、飼い鳥の世話をする飼い主が利用することを前提としています。

本サービスは、満14歳未満の児童の個人情報を法定代理人の同意なく収集しません。満14歳未満の児童が本サービスを利用する場合は、法定代理人（保護者）の指導・監督のもとでご利用いただくことを推奨します。

運営者は、法定代理人の同意なく満14歳未満の児童の個人情報が収集されたことを認識した場合、遅滞なく当該情報を消去します。児童の個人情報の閲覧・削除等については、第15条の連絡先までお問い合わせください。

第9条（Cookieおよび行動情報の処理）

本サービスは、ターゲティング広告を運営していません。ただし、上記の分析ツールは、利用統計および使いやすさの分析のため、広告識別子・端末識別子等を利用することがあります。

利用者は、端末の設定から広告識別子のリセット・削除またはパーソナライズド広告の制限を行うことにより、一部の収集を制限することができます。

第10条（個人情報の消去の手続および方法）

利用者がアプリを削除すると、端末に保存された情報および匿名識別子は削除されます。分析サービスに送信された情報は、各提供者の保管ポリシーに従い、保有期間の経過後に消去されます。サーバーへ送信された録音ファイルおよび録音情報は、収集日から180日経過後に自動的に消去されます。

電子ファイル形式の情報は、復元または再生できないよう安全に削除します。

第11条（個人情報の安全性確保措置）

運営者は、個人情報の安全性を確保するため、次の措置を講じています。

  • 通信経路の暗号化：収集されるすべての情報は、情報通信網を通じて暗号化（HTTPS/TLS）して送信されます。
  • 管理的・技術的保護措置：個人情報へのアクセス権限の管理など、合理的な管理的・技術的保護措置を維持します。

ただし、情報通信網を通じた送信や電子的な保管方法は完全に安全とはいえないため、運営者は絶対的な安全性を保証するものではありません。

第12条（情報主体の権利・義務およびその行使方法）

利用者は、個人情報の保護に関して次の権利を行使することができます。

  • 個人情報の閲覧の請求
  • 個人情報の訂正・削除の請求
  • 個人情報の処理停止の請求
  • 同意の撤回の請求

これらの請求は、下記第15条の連絡先を通じて行うことができます。

米国の一部の州（例：カリフォルニア州、バージニア州、コロラド州、コネチカット州、ユタ州、テキサス州）に居住する利用者は、居住する州の法律に基づき、次の権利の全部または一部を有する場合があります。

  • 運営者が収集した個人情報を知る権利および閲覧する権利
  • 個人情報の削除を求める権利
  • 不正確な個人情報の訂正を求める権利
  • 個人情報の「販売」または「共有」およびターゲティング広告を拒否（オプトアウト）する権利
  • センシティブな個人情報の利用制限を求める権利
  • 権利の行使を理由に差別されない権利

1. 収集する個人情報のカテゴリー

カリフォルニア州消費者プライバシー法（CCPA/CPRA）上のカテゴリーでは、運営者は、識別子（端末識別子および広告識別子）、インターネットその他の電子ネットワーク活動情報（アプリの利用履歴およびセッションリプレイ）、おおよその位置情報（市区町村・地域レベルであり、精密な位置情報ではありません）、音声情報（音声収集に同意した場合の録音ファイル）を収集します。社会保障番号などの政府発行の識別番号、金融口座情報、精密な位置情報、生体情報は収集しません。

2. 販売および共有

運営者は、金銭的対価を得て個人情報を販売することはなく、利用者にターゲティング広告を提供するために個人情報を利用することもありません。ただし、分析ツールの提供者は広告識別子および端末識別子を収集します。これが関連する州法上のクロスコンテキスト行動広告（cross-context behavioral advertising）のための「共有」に該当する範囲において、利用者は端末の広告設定およびiOSでのトラッキングの拒否（第7条参照）により、いつでもこれを拒否できます。運営者は、16歳未満の消費者の個人情報をそれと知りながら販売または共有することはありません。

3. センシティブな個人情報

運営者は、利用者の特性を推測する目的で精密な位置情報その他のセンシティブな個人情報を収集することはなく、法律で認められた目的を超えてセンシティブな個人情報を利用または開示することはありません。

4. 権利の行使方法

権利の行使は、メール（joynnovate@gmail.com）にてご請求いただけます。本サービスは会員登録・ログインなしで運営されているため、運営者は収集した分析情報を通常は利用者の身元と結び付けることができず、そのため特定の利用者の情報を特定することに制約が生じる場合があります。情報を管理する最も効果的な方法は、アプリを削除すること（端末内の情報および匿名識別子が削除されます）と、第7条に定める選択方法を利用することです。運営者は、権利の行使を理由に利用者を差別することはありません。居住する州の法律が異議申立ての手続を定めている場合、利用者は運営者の回答に返信する方法で異議を申し立てることができます。

5. カリフォルニア州「Shine the Light」法

運営者は、第三者のダイレクトマーケティング目的のために、個人情報を第三者に提供することはありません。

第14条（欧州経済領域・英国・スイスに居住する利用者に関する追加事項）

欧州経済領域（EEA）、英国およびスイスに居住する利用者には、EU一般データ保護規則（GDPR）およびこれに準ずる法律に基づき、本条が追加で適用されます。本条に定めのない事項は、第1条から第13条までの定めに従います。

1. 取扱いの法的根拠

  • プッシュ通知等のアプリ機能の提供：利用者が求めたサービスを提供するために必要な取扱い（GDPR第6条第1項(b)）
  • 異常終了（クラッシュ）およびエラーの診断、アプリの互換性および性能の改善：安定したサービスを提供するという運営者の正当な利益（同項(f)）
  • アプリの利用統計および使いやすさの分析：iOSでトラッキングを許可した場合は利用者の同意（同項(a)）、それ以外の場合はサービスを改善するという運営者の正当な利益（同項(f)）
  • 録音ファイルおよび録音情報の収集：利用者の同意（同項(a)）

運営者は、正当な利益を根拠として取り扱う場合、利用者の権利および利益を侵害しない範囲に取扱いの項目を限定します。運営者は、利用者に法的効果またはこれと同様の重大な影響を及ぼす自動化された意思決定やプロファイリングを行いません。

2. データ主体の権利

利用者は、第12条の権利に加えて、次の権利を有します。

  • 取扱いの制限の権利：情報の正確性について争っている期間など、法律に定める場合に取扱いの制限を求める権利
  • データポータビリティの権利：同意またはサービスの提供に必要な取扱いを根拠として自動的に処理される情報を、構造化された形式で受け取り、または他の事業者に移行するよう求める権利
  • 異議を述べる権利：正当な利益を根拠とする取扱いに対して、いつでも異議を述べる権利
  • 同意を撤回する権利：同意はいつでも撤回することができ、撤回前に行われた取扱いの適法性には影響しません

権利の行使は第15条の連絡先までご請求いただけます。運営者は、請求を受けた日から1か月以内に回答します。本サービスは会員登録・ログインなしで運営されているため、運営者が利用者を識別できない情報については、利用者が識別に必要な追加情報を提供しない限り、権利の行使が制限される場合があります（GDPR第11条）。

3. 監督機関に苦情を申し立てる権利

利用者は、居住地、勤務地または侵害が発生した場所のデータ保護監督機関に苦情を申し立てることができます。たとえばスペインでは、スペインデータ保護庁（AEPD、www.aepd.es）に申し立てることができます。

4. 欧州経済領域外への移転

情報を欧州経済領域外へ移転する場合は、次の保護措置を適用します。

  • 大韓民国の運営者およびソウルリージョンのサーバー：欧州委員会による大韓民国に関する十分性認定（2021年12月）
